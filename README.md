## Featured Projects

### [TaskFlow](https://github.com/abhi-byte62/task-flow)
> Real-time collaborative task management platform designed around modern full-stack engineering and collaborative workflows.

**Tech:** React • Node.js • Express • PostgreSQL • Prisma • Redis • Socket.io

**Engineering highlights:**
- Real-time collaborative task updates using WebSockets
- Optimistic UI for responsive drag-and-drop interactions
- Workspace and board-based architecture
- Role-based access control
- Optimistic concurrency handling for conflicting updates
- PostgreSQL transactions, indexes, and relational data modeling
- Redis-backed caching and rate limiting
- Automated testing and CI/CD

**Why it matters:**
Built to explore how modern collaborative applications handle synchronization, concurrency, persistence, performance, and reliability across the full stack.

### [Specter Proxy](https://github.com/abhi-byte62/specter-proxy)
> HTTP/HTTPS traffic interception and fault-injection proxy for testing network behavior and service resilience.

**Technical highlights:**
- HTTP/HTTPS traffic interception using low-level streams
- Local CA-based TLS inspection
- Configurable latency injection and failure simulation
- Request/response filtering
- Real-time terminal metrics and traffic visibility

**Why it matters:**
Explores networking fundamentals and practical techniques for understanding, testing, and debugging application traffic.

### [Packet Sniffer 3D](https://github.com/abhi-byte62/packet-sniffer-3d-)
> Interactive visualization of network traffic and packet flows for analysis and debugging.

**Technical highlights:**
- PCAP parsing and live localhost traffic streaming
- Binary payload inspection with a hex viewer
- TLS-aware data masking
- High-frequency traffic visualization
- Interactive network topology representation

**Why it matters:**
Bridges low-level networking concepts with an interactive visualization layer, making packet-level behavior easier to understand and investigate.
